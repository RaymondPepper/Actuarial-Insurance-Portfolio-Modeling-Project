# Actuarial-Insurance-Portfolio-Modeling-Project

This project simulates a fictional insurance portfolio and applies several common actuarial techniques using Python.

## Project Overview

The model analyzes:

- Claim frequency and severity
- Insurance pricing
- Plan-level pricing
- Reserve estimation
- Excess-of-loss reinsurance
- Underwriting profitability
- Future loss forecasting

The portfolio contains 10,000 simulated policies across Basic, Standard, and Premium plans. Historical claims are generated using lognormal severity distributions, and pricing is based on expected loss costs, expenses, and profit assumptions.

## Key Results

- Overall claim frequency: 10%
- Average claim severity: approximately $4,742
- Indicated premium: approximately $677 per policy
- Underwriting profit before reinsurance: approximately $338,727
- Total reserve estimate: approximately $1.929 million
- Profit after reinsurance: approximately $314,121
- Forecast premium: approximately $732 per policy
- Required rate increase: 8.12%
